# ✨ AI-Driven Web Interface Generator

Generate beautiful, fully functional web interfaces (HTML/CSS/JS) from simple natural language prompts using an AI model.

---

## 🚀 Overview

This project lets users input a prompt (e.g., "Create a login form with a blue background"), and instantly generates:
- HTML structure
- CSS styling
- JavaScript behavior  
...all rendered live in a browser interface!

It combines **frontend design**, **AI model inference**, and **live preview rendering** into a single powerful tool.

---

## 🧰 Tech Stack

- 🧠 **Model**: Custom fine-tuned model (trained on RICO dataset) using Hugging Face
- 🐍 **Backend**: FastAPI (Python)
- 🌐 **Frontend**: HTML, CSS, JavaScript, Bootstrap
- ☁️ **Deployment**: Hosted on AWS EC2
- ⚙️ **Rendering**: Uses `<iframe>` and code split logic for live previews
---

## 💡 Features

- 🧾 Prompt-based UI generation
- 🎨 Code tabs: HTML / CSS / JavaScript
- 🔄 Live preview in real-time
- 🖱️ Drag-and-drop interface for further UI edits
- 📦 Fully responsive, Bootstrap-powered layout
